## What this branch did

1. **Full inventory -> overflow sack.** `Inventory.give()` adds and hands
   anything that doesn't fit to an overflow sink; the game drops it in a
   sack at the player's feet (`PlanetBlockInteraction.dropAtFeet`). The
   sack is the old garbage pile (record kind `garbagePile`, so saves and
   MP sync carry over); it merges into the sack on the same tile, spills to
   neighbouring tiles when full, and anyone who walks up picks up what fits
   (inside the MP trade ledger, so a refused write undoes it). Use
   `give()` for "the player gets this"; `addItem()` only when the caller
   keeps the remainder itself. One stacking rule: `addToSlots` in
   `Inventory.ts`. PR #121's "refuse the craft" was replaced by "craft and
   drop". Tests: `scripts/overflow-sack.test.ts`,
   `scripts/mp-e2e/sack-shots.cjs` (two clients).
2. **Sack and campfire visuals.** Sack: lathe mesh, Sweaft-64 burlap
   texture, v mapped by height (`PlayerConfig SACK`). Campfire: built model
   in `Cookers.ts buildCampfire` (stone ring, log teepee, unlit flickering
   flame cards), atlas `public/textures/technology/campfire.png`, sizes in
   `CookingConfig CAMPFIRE_MODEL`. Both textures come from
   `scripts/gen-item-icons.py`, which imports the palette and check from
   `gen-biome-textures.py`.
3. **Space exploration, phases 8-9 (change now 42/42).** Submarine and
   gas-giant diver (`src/vehicles/`), depth bands for deuterium / helium-3
   / metallic hydrogen, the reward and cross-route tests, the integration
   run `scripts/mp-e2e/exploration-run.cjs`, and a landing fix in
   `RocketController` (a rocket resting on the ground could read a hair
   above the touchdown threshold and never land).
4. **Friendship / NPCs, planned and groups 1-2 built.** Change
   `openspec/changes/friendship-npcs/`. Built: `src/config/NpcConfig.ts`,
   the pure rules in `src/shared/npc/` + `src/shared/worldTime.ts`, the
   server bundle `server-js/npc-core.js` (generated by
   `npx tsx scripts/gen-npc-core.ts`, drift-tested), server occupancy /
   wake / catch-up / tick / sleep in `server.js`, and the admin People tab.
   `design.md` has "As built" notes where the agent deviated (homes placed
   by a client ground test, event-based food store, trader records sent
   world-wide).

## How to check visuals headless

`npx vite build && npx vite preview --port 4179`, then a Playwright script
against `http://localhost:4179/tenebris/js/?debug` (game at
`window.__tenebris`; helpers in `scripts/mp-e2e/page-helpers.js`; launch
Chromium with `--use-gl=angle --use-angle=swiftshader
--enable-unsafe-swiftshader --ignore-gpu-blocklist`). The `?world=<name>`
param gives a fresh save slot. Stand on the sub-solar tile
(`planet.getSunDirection()`) for a daytime shot, its negation for night.
